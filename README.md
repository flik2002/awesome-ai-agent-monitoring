# Awesome AI Agent Monitoring

> A curated list of tools, platforms, and resources for monitoring AI agents in production.

## Why Monitor AI Agents?

As AI agents move from experiments to production, teams need visibility into agent health, performance, costs, and reliability. Without monitoring, silent failures, cost overruns, and degraded outputs go undetected.
